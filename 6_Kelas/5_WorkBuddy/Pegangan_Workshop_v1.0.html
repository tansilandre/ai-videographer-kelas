Sesi 1 · Pasang

Tiga langkah. AI yang mengunduh dan memasang.

Kamu memasang WorkBuddy. AI di dalamnya mengambil AI Videographer dari GitHub dan memasang semua alatnya. Kuncimu kamu tempel sendiri, di halaman lokal, bukan di chat.

  1. 1

    Pasang WorkBuddy

    KAMU
    • Sudah daftar lewat link undangan? Unduh aplikasinya dari workbuddy.ai (tombol Download).
    • Windows: jalankan file .exe. Muncul layar biru "Windows protected your PC"? Klik More info, lalu Run anyway.
    • Mac: buka file .dmg, seret WorkBuddy ke folder Applications.
    • Buka WorkBuddy dan masuk dengan akun yang sama.

    Pertama kali dibuka bisa butuh 30–60 detik. Tunggu saja.

  2. 2

    Minta AI memasang AI Videographer

    AI
    • Buat folder baru, misalnya AI_Videographer di Documents.
    • Di WorkBuddy: tugas baru, Select Folder ke folder itu, model glm-5.3-flash, izin Default Permissions.
    • Tempel pesan ini, lalu Enter:
    Windows · tempel ke WorkBuddy

    Pasang AI Videographer: unduh https://github.com/tansilandre/ai-videographer-kelas ke folder ini (pakai git clone kalau git ada; kalau tidak, unduh https://github.com/tansilandre/ai-videographer-kelas/archive/refs/heads/main.zip lalu ekstrak ke subfolder ai-videographer-kelas), lalu jalankan powershell -ExecutionPolicy Bypass -File setup.ps1 di folder itu dan ikuti yang dicetaknya.

    Pakai Mac? Pesannya yang ini
    Mac · tempel ke WorkBuddy

    Pasang AI Videographer: clone https://github.com/tansilandre/ai-videographer-kelas.git ke folder ini (atau ke subfolder ai-videographer-kelas kalau folder ini tidak kosong), lalu jalankan bash setup.sh di folder itu dan ikuti yang dicetaknya.

    Di Mac, klik Install kalau jendela Apple muncul, lalu bilang "jalankan setup lagi". Kalau Homebrew belum ada, AI memberimu satu baris untuk app Terminal, karena butuh password Mac-mu.

    • WorkBuddy bertanya sebelum tiap perintah: klik Allow. Windows bertanya "allow this app to make changes"? Klik Yes.
    • Pemasangan Python dan FFmpeg butuh beberapa menit. Biarkan berjalan.

    Perintah yang wajar di langkah ini:

    git clone … atau unduh main.zippowershell -ExecutionPolicy Bypass -File setup.ps1winget install … Python / FFmpegpython -m pip install pillow

    Perintah lain yang aneh? Klik Cancel, lalu tanya: "Kenapa perintah ini perlu?"

  3. 3

    Tempel kunci, lalu buka ulang

    KAMU
    • Halaman Setup AI Videographer terbuka di browser. Tempel kunci kie.ai (dan OpenRouter kalau sudah ada), lalu klik Simpan. Halaman itu langsung mengecek saldo kie.ai-mu.
    • Tutup WorkBuddy sepenuhnya. Windows: klik kanan ikon WorkBuddy di taskbar atau di pojok kanan bawah, pilih Quit. Mac: Cmd + Q.
    • Buka lagi WorkBuddy. Tugas baru, Select Folder ke folder yang disebut di akhir setup (…\ai-videographer-kelas).
    • Pilih Expert Expert Center › My Experts › AI Videographer, model glm-5.3-flash, lalu klik Cek setup.

    Halaman setup tertutup? Bilang ke AI: "buka halaman setup".

    Expert Center

    Buat video baru.Lanjutkan video saya.Cek setup.

Sesi 2 · Buat reel pertama

Lima jawaban, tiga klik, satu reel.

Expert mengerjakan satu langkah, lalu melapor dalam satu baris: apa yang dikerjakan, kredit terpakai, apa berikutnya. Di tiga gerbang ia berhenti dan menunggu klikmu.

  1. 1

    Klik "Buat video baru."

    KAMU
    • Folder ai-videographer-kelas, Expert AI Videographer, model glm-5.3-flash.
    • Expert bertanya lima hal dalam satu pesan. Jawab semuanya sekaligus, dan lampirkan foto kalau ada:
    1. Nama brand atau klien?
    2. Apa yang dijual, di mana, mulai harga berapa?
    3. Tiga hal yang membuatnya layak?
    4. Penonton harus melakukan apa di akhir (DM, WhatsApp, datang)?
    5. Ada foto asli tempatnya? Tanpa foto, semua gambar dibuat AI.
    Latihan tanpa klien? Tempel ini sebagai gantinya. Brief-nya fiktif: Rumah Melati dari agen Griya Cerah.
    Tempel ke WorkBuddy

    Buat reel dari brief latihan di 6_Kelas/3_Latihan/Brief_Latihan_v1.2.md.

  2. 2

    Expert menulis rencana

    AI
    • Naskah dan daftar shot. Butuh 10–15 menit: glm-5.3-flash murah, tapi berpikirnya lama.
    • Izinkan perintah yang diawali python 2_Tools/vg/vg.py. Itu alat kita.
    • Diam lebih dari 2 menit? Ketik "lanjut".
    Contoh balasan Expert: Rencana selesai: 8 shot, 26 detik, hook di 2 detik pertama. Kredit terpakai: 0. Berikutnya: 3 style frame untuk look.
  3. GERBANG 1 · LOOK
    3

    Setujui look-nya

    KAMU
    • Expert mengirim link halaman review. Link ini hanya jalan di laptop-mu.
    • Suka? Klik Approve look
    • Belum? Tulis catatan di gambar yang harus berubah, lalu klik Done, back to the agent
    • Kembali ke WorkBuddy, ketik "sudah".
    Expert: Style frame siap. Buka halaman review: http://127.0.0.1:52011/?t=…

    Contoh gambar dari studi kasus kelas (Tebak Harga).

  4. 4

    Semua gambar dibuat

    AI
    • Lembar referensi (orang, tempat, produk) dan frame pertama tiap shot.
    • Expert melihat setiap gambar dan membuat ulang yang jelek sebelum kamu melihatnya.
    • Satu gambar sekitar 10 kredit. Kamu cukup menunggu.
  5. 5

    Suara, musik, dan animatic

    AI
    • Narasi dan musik dibuat dulu, sebelum video. Potongan reel mengikuti suara.
    • Lalu animatic: seluruh reel sebagai gambar diam, dengan suara, caption, dan grafis.
    • Ditanya soal suara? Pilih yang paling cocok dengan penontonmu.
  6. GERBANG 2 · REEL
    6

    Setujui seluruh reel sebagai gambar

    KAMU
    • Tonton animatic di halaman review seperti penonton biasa.
    • Cek: satu dunia, satu cahaya, hook terbayar di akhir, produknya kelihatan.
    • Suka? Approve reel. Belum? Catatan, lalu Done, back to the agent.
    • Ketik "sudah" di WorkBuddy.
    Kenapa di sini? Gambar murah, video mahal. Perbaiki sekarang, sebelum membayar video.
  7. GERBANG 3 · VIDEO
    7

    Bayar satu klip pilot dulu

    KAMU
    • Bagian Video di halaman review menunjukkan biaya tiap klip.
    • Klik Approve · 35 credits untuk klip pertama saja. Browser bertanya sekali lagi. Klik OK.
    • Ketik "sudah". Satu klip butuh sekitar 3–6 menit.
    • Tonton pilotnya. Gerak, cahaya, dan harga pas? Baru setujui sisanya.

    Satu klik membayar satu take satu klip. Klip gagal tidak memotong kredit, tapi mencoba lagi butuh klik baru.

  8. 8

    Edit final

    AIKAMU
    • Expert memotong klip mengikuti suara, lalu menambah caption, musik, dan efek suara.
    • Reel final ada di folder 99_Output di dalam folder proyek.
    • Tonton, beri catatan, lalu kirim ke klien.

Cara bicara ke Expert

Tidak perlu hafal perintah. Bahasa biasa saja.

Lanjut

Menjalankan vg next dan mengerjakan satu langkah berikutnya.

Sudah

Membaca klik dan catatanmu di halaman review, lalu lanjut.

Kenapa berhenti?

Menjelaskan langkah yang sedang menunggu kamu.

Buka lagi halaman review

Halaman tertutup setelah Done. Ini membukanya lagi.

Buka halaman setup

Untuk mengganti kunci, atau setelah isi saldo.

Peta halaman review

BagianIsinyaTombol
LookTeks look dan style frameApprove look
Reference sheetsLembar karakter, lokasi, produkpilih take v1, v2, …
ReelSetiap beat dengan gambar dan teksnyakotak catatan per gambar
AnimaticSeluruh reel sebagai gambar diamApprove reel
VideoSetiap klip, panjangnya, biayanyaApprove · N creditsNew takeApprove all not made
Paling bawahDone, back to the agent

Halaman review milikmu. Expert tidak pernah mengklik apa pun di sana untukmu.

Uang: apa membayar apa

kredit WorkBuddyotak glm-5.3-flash, sudah ada di WorkBuddy
10kredit kie.ai per gambar (ukuran 2K bawaan)
35kredit kie.ai per klip video 8 detik
beberapa sendolar per take narasi atau musik, di OpenRouter

Kalau macet

Yang sering terjadi, dan cara keluarnya

Microsoft Store terbuka saat perintah python3Di Windows, python3 hanya jalan pintas ke Store.Ketik: "Di Windows pakai python, bukan python3."
winget tidak ditemukanWindows-mu belum punya App Installer versi baru.Perbarui App Installer dari Microsoft Store, lalu ketik "jalankan setup lagi".
Caption tidak muncul, ada pesan tentang PillowPenggambar caption belum terpasang.Ketik: "Jalankan python -m pip install --user pillow, lalu ulangi."
Expert AI Videographer tidak munculWorkBuddy belum ditutup penuh, atau setup belum selesai.Quit dari system tray, buka lagi. Masih tidak ada? Minta AI menjalankan setup lagi dan baca pesannya.
Expert bilang tidak bisa menjalankan perintahIzin perintah ditolak.Izinkan perintahnya (Default Permissions), lalu ketik "lanjut".
"WorkBuddy tidak mendukung pembuatan video"Model bingung dengan alat bawaan WorkBuddy.Ketik: "Pakai alat vg di folder ini. Jalankan vg next."
REFUSED: VG_APPROVAL_MODE=page …Expert mencoba menyetujui sendiri, dan alatnya menolak. Ini aman.Setujui di halaman review, lalu ketik "sudah".
Link review tidak terbukaHalaman sudah tertutup setelah Done.Ketik "buka lagi halaman review".
Kunci salah, atau PROVIDER ERROR … 402Kunci kie.ai salah, atau saldonya habis.Isi saldo di kie.ai, lalu ketik "buka halaman setup" dan tempel kuncinya lagi.
Perintah kehabisan waktuTugasnya mungkin masih jalan di kie.ai.Minta Expert menjalankan vg resume. Jangan mengulang perintahnya: itu membayar dua kali.
